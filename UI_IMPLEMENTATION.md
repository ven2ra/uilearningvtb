## Assets

`src/assets/reference/` содержит локальные изображения баннеров, промокарточек, историй и эмитентов. Проверено соответствие файлов embedded-изображениям HTML по SHA-256. В сборку включается явный список используемых изображений из `referenceImages.ts`; исходные локальные файлы не удалялись.

Дополнительно извлечены 20 SVG в `src/assets/reference/icons/` и три начертания Inter (400, 500, 600) в `src/assets/reference/fonts/`. У SVG удалены snapshot-атрибуты; подписи дат графика адаптированы для мобильного экрана. Production-скрипты, API, service workers и инфраструктура исходного сайта не переносились. iframe и dangerouslySetInnerHTML не используются.

## Состояние и ограничения прототипа

- Начальный вид счетов воспроизводит 116 ₽ и четыре счёта из HTML. Их карточки открывают детали снимка. После операций главная показывает существующий тестовый счёт ···4821 и его актуальный баланс. Эти источники данных не смешиваются при расчётах сделок.
- Избранное использует существующие учебные инструменты и сохраняется с остальным состоянием.
- Предложения и новости показывают локальное содержимое макета. Для карточек без учебного инструмента доступны детали, без имитации банковского оформления.
- Индекс содержит исходный месячный снимок; недельный вид показывает его последний участок. Новые котировки для этого графика не выдумываются.
- Настройки вида главной и переключатель уведомлений профиля действуют в текущем сеансе.
- Отдельного Login в репозитории нет, поэтому проверить путь с авторизацией невозможно. Проверен существующий запуск через Splash → Home.

## Проверки

- `pnpm install` и `pnpm build` выполнены успешно через `npm exec --package=pnpm -- pnpm …`, поскольку pnpm отсутствовал в PATH. Build включает `tsc --noEmit`. Дополнительных scripts проверок в package.json нет.
- Playwright / Chromium: Home → Portfolio → Home → Profile → Home на 375, 390, 430, 768, 1024, 1280 и 1440 px. Проверены скриншоты, отсутствие горизонтального переполнения и отсутствующих изображений.
- Полный онбординг: действия → пополнение → вывод → документы → достижения → помощь → завершение; состояние `onboarding: done` сохраняется.
- Полная тренировка: 11 заданий, пополнение, заказ документа, годовой график, покупка, портфель, история, продажа, завершение и выход. Получено 10 достижений; баланс обычного счёта остался 0; прогресс сохранён после reload.
- Пополнение обычного mock-счёта отражается на главной. Добавление в избранное сохраняется после reload.
- На 375 px проверены покупка и продажа на обычном mock-счёте; учебный счёт не изменился. Кнопки сделок располагаются над плавающей навигацией.
- Проверены скрытие сумм, настройки вида, баннеры, вкладки аналитиков, 21 идея, выбор периода, раскрытие AI-саммари, карточки, native dialog / Escape и переход из подборки в инструмент.
- В записанных проверках нет ошибок React/JavaScript и внешних HTTP-запросов. Снимки и результаты запусков сохранены локально в игнорируемой `.local-qa/`.
