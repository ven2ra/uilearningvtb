# ВТБ Мои Инвестиции: прототип онбординга и обучения

Кликабельный фронтенд-прототип (React 19 + Vite + Tailwind CSS v4) — концепт системы онбординга и встроенного обучения инвестициям. Все данные тестовые: реальных платежей, сделок и банковских API нет.

```bash
pnpm install
pnpm dev      # http://localhost:5173
pnpm build    # проверка типов + сборка в dist/
```

На широком экране прототип открывается в рамке телефона с панелью быстрых состояний, на мобильном — на весь экран.

## Что внутри

| Слой | Где | Что показывает |
| --- | --- | --- |
| Реальное приложение (синий) | `src/screens/*` | Главная, портфель, рынок, карточка инструмента, история, «Действия» → Пополнить / Вывести / Отчёты и справки → Заказать документ / Скачать готовые |
| Онбординг | `src/tour/Tour.tsx` | Первый запуск → spotlight-подсказки: Действия → Пополнить → Вывести → Отчёты и справки → Заказать документ → Скачать готовые → карточка обучения → «Помощь». Можно закрыть на любом шаге |
| «Помощь» | кнопка в шапке каждого экрана | Повторяет подсказки именно для текущего экрана (включая меню «Действия») |
| Фейковые торги (фиолетово-розовый) | `mode-training` | Постоянный баннер «ФЕЙКОВЫЕ ТОРГИ», 1 000 000 ₽ виртуальных, те же экраны, виртуальные покупка/продажа/пополнение/вывод/документы |
| Обучение через действие | `src/lib/training.ts` | 7 этапов, 11 заданий, проверка по реальным действиям в интерфейсе, ошибки с подсказкой, достижения, статус, история прогресса |
| Return loop | карточка на главной | «Вы прошли N из 7 этапов», следующий этап, сколько заданий до достижения, «Продолжить обучение»; после финиша — «Готовы продолжить самостоятельно?» |

Прогресс хранится в `localStorage` (ключ `vtb-learning-proto-v1`). Сбросить или открыть нужное состояние можно в разделе «Ещё» → «Состояния прототипа» или на боковой панели на десктопе.

## Дизайн-система

Токены (цвета, типографика, радиусы, тени, отступы, z-index) взяты из дизайн-системы «ВТБ Мои Инвестиции» и лежат в `src/index.css`. Логотипы и фирменная графика не используются: вместо знака — текстовая подпись, вместо логотипов эмитентов — цветные монограммы.

Одно осознанное отступление от дизайн-системы: в тренировочном режиме CTA окрашены в `training` (фиолетовый), а не в `brand`, чтобы тренировку нельзя было спутать с реальным приложением. Текстовая маркировка «виртуальные деньги» при этом есть везде, так что режим различается не только цветом.
