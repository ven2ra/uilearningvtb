# ВТБ Мои Инвестиции: прототип онбординга и обучения

Кликабельный фронтенд-прототип (React 19 + Vite + Tailwind CSS v4) — концепт системы онбординга и встроенного обучения инвестициям. Все данные тестовые: реальных платежей, сделок и банковских API нет.

```bash
pnpm install
pnpm dev      # http://localhost:5173
pnpm build    # проверка типов + сборка в dist/
```

На широком экране прототип открывается в рамке телефона с панелью быстрых состояний, на мобильном — на весь экран.

## Развёртывание на сервере

Прототип — статический сайт. На сервере нужен Node.js 20+ (только для сборки) и nginx.

```bash
git clone -b claude/fervent-curie-q4sskq https://github.com/ven2ra/uilearningvtb.git /opt/vtb-proto
sudo bash /opt/vtb-proto/deploy/deploy.sh          # сборка → /var/www/vtb-proto
sudo cp /opt/vtb-proto/deploy/nginx.conf /etc/nginx/sites-available/vtb-proto
sudo ln -sf /etc/nginx/sites-available/vtb-proto /etc/nginx/sites-enabled/vtb-proto
sudo nginx -t && sudo systemctl reload nginx
```

Обновление: повторно запустить `deploy/deploy.sh`.

## Что внутри

| Слой | Где | Что показывает |
| --- | --- | --- |
| Реальное приложение (синий) | `src/screens/*` | Главная, портфель, рынок, карточка инструмента, история, «Действия» → Пополнить / Вывести / Отчёты и справки → Заказать документ / Скачать готовые |
| Онбординг | `src/tour/Tour.tsx` | Первый запуск → spotlight-подсказки: Действия → Пополнить → Вывести → Отчёты и справки → Заказать документ → Скачать готовые → карточка обучения → «Помощь». Можно закрыть на любом шаге |
| «Помощь» | кнопка в шапке каждого экрана | Меню: подсказки к текущему экрану, продолжить первую покупку, переключиться на фейковые торги и обратно (на том же экране), достижения, повторить знакомство |
| Фейковые торги (фиолетово-розовый) | `mode-training` | Постоянный баннер «ФЕЙКОВЫЕ ТОРГИ», 1 000 000 ₽ виртуальных, те же экраны, виртуальные покупка/продажа/пополнение/вывод/документы |
| Обучение через действие | `src/lib/training.ts` | 7 этапов, 11 заданий, проверка по реальным действиям в интерфейсе, ошибки с подсказкой, достижения, статус, история прогресса |
| Первые шаги | карточка на главной | Знакомство → пополнение счёта → первая покупка. После пополнения — CTA «Перейти на биржу» |
| Баннер биржи | `MarketOfferSheet` | При первом заходе на биржу: «Попробовать на фейковых торгах» или «Учиться в приложении». Оба пути ведут к первой покупке: подсказка начинает с фонда ликвидности (от ~2 ₽), но на каждом шаге есть «Выберу сам» — купить можно любой актив |
| Достижения | `src/lib/achievements.ts` | 18 наград почти за каждое первое действие в обоих режимах; тост за обычные, праздничное окно за крупные (первая покупка, фонд ликвидности, первая акция, фьючерс на фейковых торгах). Счётчик в шапке, экран «Мои достижения» |
| Срочный рынок | вкладка «Фьючерсы» | В реальном режиме закрыт тестом; «Попробовать на фейковых торгах» переключает режим, оставляя на той же карточке |
| Return loop | карточка на главной | «Вы прошли N из 7 этапов», следующий этап, сколько заданий до достижения, «Продолжить обучение»; после финиша — «Готовы продолжить самостоятельно?» |

Обучение нелинейное: действие из будущего этапа (например, покупка на фейковых торгах до прохождения первых этапов) засчитывается, когда программа до него дойдёт. Любую подсказку и квест можно закрыть и вернуться к ним через «Помощь».

В реальном режиме пополнение, вывод и сделки имитируются на тестовом счёте — это прототип, без банковских API. Счёт нового клиента начинается с 0 ₽.

Прогресс хранится в `localStorage` (ключ `vtb-learning-proto-v2`). Сбросить или открыть нужное состояние можно в разделе «Ещё» → «Состояния прототипа» или на боковой панели на десктопе.

## Дизайн-система

Токены (цвета, радиусы, тени, шрифт) взяты из статичного HTML-среза дизайн-системы «ВТБ Мои Инвестиции» и лежат в `src/index.css`: фон `#F3F5F7`, белые карточки с радиусом 16px, элементы управления — 12px, акцент `#0062FF`, успех `#12B76A`, ошибка `#F04438`. Шрифт — Inter, подключён из Google Fonts. Логотипы и фирменная графика не используются: вместо знака — текстовая подпись, вместо логотипов эмитентов — цветные монограммы.

Одно осознанное отступление от дизайн-системы: в тренировочном режиме CTA окрашены в `training` (фиолетовый), а не в `brand`, чтобы тренировку нельзя было спутать с реальным приложением. Текстовая маркировка «виртуальные деньги» при этом есть везде, так что режим различается не только цветом.
